# OI 学习资料归档

按专题、比赛和题库来源分目录存放，只保留源码与题解；编译产物和编辑器配置不入库。

## 约定

- 文件名：`题号 + 题目名`，例如 `P3386 Hungary.cpp`
- 目录：一题一文件夹，或按日期归档
- 提交信息：`add: <比赛/题号> <简述>`，一题一次提交
- 每日/每完成一题推送一次即可，不必追求"实时"

## 未纳入仓库的内容

以下内容被 `.gitignore` 排除，**文件本身仍在本地，只是不进版本库**：

| 类型 | 原因 |
| --- | --- |
| `.cph/`、`.vscode/`、`.vs/` | 编辑器与插件的本地配置 |
| `*.exe`、`*.o`、`*.obj`、`*.pdb`、`*.ipch` | 编译产物，可随时重新编译 |
| `*.iso`、`*.AppImage` | 超过 GitHub 单文件 100MB 上限 |
| `*.zip`（answers 压缩包，共约 138MB） | 体积大且无版本控制价值；如需留存建议放 Release 附件 |

## 环境

- C++17（`-O2 -std=c++17`），Windows + GCC / MinGW
- 编辑器：VS Code + CPH（测试样例保存在本地 `.cph`，不入库）

## 维护提醒

- 仓库末尾有一批"无扩展名的 ELF 可执行文件"按路径精确排除。
  以后若 `git status` 里冒出可疑的无扩展名文件，多半又是编译产物，
  在 `.gitignore` 末尾补一条对应路径即可。
