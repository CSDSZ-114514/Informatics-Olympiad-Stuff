# OI 学习资料归档

个人 OI（信息学奥林匹克）代码与题解仓库，用于**备份、跨设备同步和版本回溯**。
按专题、比赛和题库来源分目录存放，只保留源码与题解；编译产物和编辑器配置不入库。

## 目录结构

| 目录 | 内容 | 源码数 |
| --- | --- | ---: |
| `Competition/` | 比赛实战（按日期归档） |- |
| `JiaoHu/` | 交互题（P15652、P17140 等） |-|
| `kaoshi/` | 虚拟机交互文件夹 |-|
| `Luogu-common/` | 洛谷常见题练习 |-|
| `Moudle/` | 算法模块与模板|-|
| `Others/` | 其他练习 |-|
| `StudyNew/` | 新学算法专题|-|
| `程序公示/` | 部分天津赛区程序公示资料|-|
